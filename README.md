## GitHub Pages

To host at `https://mincimouse.github.io/Momentum-Personal-Growth/`:

1. Repo → **Settings** → **Pages**
2. **Build and deployment** → Source: **Deploy from a branch**
3. Branch: `main` · Folder: **`/docs`**
4. Save — live in ~1–2 minutes

App-friendly URLs (no `.md` suffix):

- `https://mincimouse.github.io/Momentum-Personal-Growth/legal/privacy-policy`
- `https://mincimouse.github.io/Momentum-Personal-Growth/legal/terms-of-service`

Until Pages is enabled, the app falls back to the GitHub-rendered markdown views in this repo.
